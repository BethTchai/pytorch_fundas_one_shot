Herein lies the sum total of the content from CampusX's [Practical Deep Learning using PyTorch](https://www.youtube.com/playlist?list=PLKnIA16_Rmvboy8bmDCjwNHgTaYH2puK7). 
Tensors, torch, autograd,torch.nn (torch.nn.Module, torch.nn.Linear(), torch.nn.Sigmoid(), torch.nn.ReLU(), torch.nn.Softmax()), torch.optim, torch.utils.data.Dataset, torch.utils.data.DataLoader etc. are covered here.

Moral: Just like _Pandas_ uses _NumPy_ arrays, so does _PyTorch_ use _tensors_ for practically every significant computation. Coding deep learning in PyTorch is like planning a kitchen recipe, whereas coding in Keras is like placing an order on Swiggy, Zomato or DoorDash, depending on what hemisphere of the wide world you are in.
